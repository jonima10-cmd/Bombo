# BOMBO — Sitio web

Landing one-page para BOMBO Guadalajara, con reservas por WhatsApp y panel demostrativo `/admin` para bloquear turnos.

## Desarrollo local

Requisitos: Node.js 20 o superior.

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`. El panel está en `http://localhost:3000/admin`.

## Estado

Reservas por WhatsApp. El panel `/admin` permite bloquear turnos en el navegador local para demostración; aún no hay base de datos compartida ni autenticación de producción.
